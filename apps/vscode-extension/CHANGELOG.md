# Change Log

All notable changes to the TLC Assist VS Code extension are documented here.

## [0.1.0] - Unreleased

- Initial extension shell: Activity Bar container with Connection, Portfolio, and Plays views.
- Editor-area workbench webview with a strict, nonce-based Content Security Policy.
- Validated `postMessage` bridge between the webview and the extension host.
- Sample-mode data provider reusing the shared workflow sample host.
- Portfolio navigation, MCEM Coach, four agent capabilities, and deterministic plays in sample mode.
- Live delegated Dataverse/MSX access is gated and not yet enabled.
