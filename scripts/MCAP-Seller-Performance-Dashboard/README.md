# MCAPS Seller Performance Dashboard

Build a private, manager-ready view of official MSX Earnings attainment, quota gaps and account-scoped pipeline from your own Quota by Accounts export, with explicit no-pipeline and unverified-coverage callouts.

Contributed by Ted Malone.

## Use

Load [`SKILL.md`](./SKILL.md). Nothing personal ships in this package. Any send, submit or write step previews first and waits for your explicit confirmation.

Requires your own Quota by Accounts CSV from MSX Earnings and a separately installed MSX MCP runtime. The viewer is loopback-only and runtime snapshots stay encrypted to your Windows user.
